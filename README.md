# D’Angelo Caffè & Gastronomia
```
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```
Edit all content in `src/data/content.js` (menu, prices, hours, images, Instagram, email, EN/IT copy).
Put photos in `public/img/` and reference them as `/img/name.jpg`.
